# Scripts de Ingesta de Datos

Esta carpeta contiene scripts para la ingesta y procesamiento de datos biométricos.

## Scripts Disponibles

- `ingest_suunto_json.py` - Ingesta de datos Suunto desde JSON exportado
- `ingest_suunto_data.py` - Ingesta alternativa de datos Suunto
- `ingest_json_simple.py` - Ingesta manual sin DAO

## Uso

```bash
# Ingesta de datos Suunto
python scripts/data/ingest_suunto_json.py
```
